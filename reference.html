Materials and boundary conditions

Material records define thermal conductivity, density, specific heat capacity and vapour diffusion resistance where applicable. Boundary conditions define the environment, temperature, relative humidity and surface resistance. Layer assignments determine which records apply to each model volume.

See standalone material libraries and Rhino layer assignments. Profile cavities may use an equivalent conductivity or the automatic frame-cavity method.

Window and glazing data

Frame configurations and sources records compatibility, source classification and component identifiers. Glazing import describes supported WINDOW-derived data. Placed components retain snapshots of their assigned properties and provenance.

Applicability and limitations

The methods guide describes the numerical model. Window and cavity calculations are thermal-only; Glaser results are steady-state screening. Review window assessment limits, frame cavity assumptions and the source scope of a supplied configuration when interpreting results.
