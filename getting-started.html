Choose an application

The standalone editor analyses layered constructions in two dimensions. The Rhino plugin analyses junctions and window details using geometry and assignments in a Rhino document. Both use the KOALA heat-transfer solver.

Begin with installation, then follow the procedure for the application you use.

First calculation in the standalone editor

  1. Open a supplied construction example, or define exterior and interior boundaries and the material layers between them.
  2. Assign material properties and check layer thicknesses, framing dimensions and boundary conditions.
  3. Run the heat-transfer analysis and inspect the calculated U-value, temperature and heat flux fields.
  4. Save the construction and review the standalone editor guide for editing and exports.

First calculation in Rhino

  1. Run Koala to open the panel. In a new document, choose Library… → Examples and place one example.
  2. Review its material assignments, indoor and outdoor boundary conditions, document units and cell size.
  3. Choose Simulate to calculate heat flow and temperatures. Inspect the result with the plane and slice controls.
  4. For Ψ or χ, review Bridge Analysis…; for Uf, Ψg, installation Ψ or Uw, review Window Analysis….
  5. Open Report… to review the results and report requirements.

See example setups, Rhino model setup and Results and reporting.

Units and model inputs

The Rhino panel follows the document units. Review dimensions, material conductivities, boundary temperatures and surface resistances before calculation. The standalone editor has its own unit preference.

Review the mesh settings and refinement checks when assessing numerical resolution. Example materials and dimensions are illustrative inputs for a model you review and adapt.
